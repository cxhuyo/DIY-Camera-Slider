# DIY 相机电动滑轨（亚克力 + 3D 打印）

## 把 Skill 交给 AI Agent 使用

本仓库自带一个完整的 AI agent 技能包（根目录的 `SKILL.md` 与 `references/` 知识库文件）。**把它交给任何支持 Skills 的 AI agent，agent 就能化身随身的滑轨组装教练**：

- **安装**：将 `SKILL.md` 和 `references/` 放入同一个文件夹（命名为 `diy-slider-assembly`）后整体复制给 agent ；其他 agent 平台按其技能安装说明导入 SKILL.md 即可
- **使用**：组装过程中随时提问，agent 会按技能内置的 14 步教程、零件对照表和排错手册给出针对性回答，例如：
  - "下一步做什么？"
  - "这颗 M5×30 螺丝装在哪里？"
  - "装完电机不动怎么办？"
- **兜底用法**：即使 agent 不支持技能系统，也可以把 `SKILL.md` 和 `references/` 里的文件直接发给 AI 作为参考资料阅读

一套零基础也能做出来的**相机电动滑轨**：亚克力激光切割 + 3D 打印 + 欧标铝型材，配步进电机驱动，可实现平滑的推拉运镜。全部图纸、3D 打印文件、材料清单、组装教程开源在本仓库。

## ✨ 特点

- **结构简单**：一根铝型材 + 4 个 POM 轮 + 同步带传动，约 1~2 小时装完
- **电动可控**：42 步进电机 + 遥控器，行程内平滑往复
- **限位保护**：两端限位开关，滑到头自动停/回头
- **电池可拆**：魔术贴 + 扎带固定 12V 锂电池，拆下充电方便
- **无需焊接电路**：仅两处用打火机烧带锡热缩管的小操作

## 🗣️ 找商家定制怎么说（复制即用）

需要**定制**的只有 3 样，其余零件照清单直接网购即可：

**① 亚克力激光切割**——把 `亚克力图纸/` 里 3 个 DXF 文件发给激光切割商家，并留言：

> 我要激光切割亚克力，图纸是 DXF 格式共 3 个文件，请按文件 1:1 切割：01 号用 8mm 厚亚克力切 2 块，02 号用 5mm 厚切 1 块，03 号用 3mm 厚切 1 块，一共 4 块。

**② 铝型材攻丝**——购买欧标 2040V 铝型材时给商家留言：

> 请帮我把这根型材的两个端面攻好 M5 或 M6 的螺纹孔，后面要用来装支架。

**③ 3D 打印代工**（没有打印机时）——把 `3D打印文件/` 里 2 个 3MF 文件发给代打印商家：

> 这是两个 3MF 打印文件：一个包含滑轨全套打印件，一个是 M3 塑料螺丝×10，请按文件里的设置直接打印，不需要改尺寸。

## ⚠️ 关键注意事项

- **控制板固定必须用 3D 打印塑料螺丝**（或笔记本小螺丝/M2 螺丝+绝缘垫片）。金属螺丝会顶到电路板背面造成短路烧板！
- 烧带锡热缩管时远离易燃物，烧到锡熔化即停，接头烫手等冷却再碰
- 同步带绷紧适度：按下去有弹性即可，太紧电机吃力、太松会跳齿
- 锂电池充电使用配套充电器，不要短路或刺破外壳

## 🖨️ 切割与打印参数

- **亚克力切割**：按 `亚克力图纸/` 内 DXF 文件标注厚度切割——01 号 8mm×2、02 号 5mm×1、03 号 3mm×1，共 4 块
- **3D 打印**：直接用 `3D打印文件/` 内 3MF 文件切片打印；没有打印机可全部改用亚克力定做 + 网购 M2 螺丝替代打印螺丝
