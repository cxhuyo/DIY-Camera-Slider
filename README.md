# DIY 相机电动滑轨（亚克力 + 3D 打印）

## 把 Skill 交给 AI Agent 使用

本仓库自带一个完整的 AI agent 技能包（根目录的 `SKILL.md` 与 `references/` 知识库文件）。**只需要把下面的仓库链接发给你的 AI agent，让它下载仓库文件并安装 skill，装好即可开始使用**：

- **仓库地址**：
  - GitHub：<https://github.com/cxhuyo/DIY-Camera-Slider>
  - Gitee（国内用户推荐，访问更快）「可能需登录」：<https://gitee.com/cxhoyo/DIY-Camera-Slider>
- **怎么用**：把链接发给支持 Skills 的 AI agent，说一句"下载这个仓库并安装里面的滑轨组装 skill"。agent 会拉取仓库文件，把 `SKILL.md` 和 `references/` 安装为技能（技能目录名 `diy-slider-assembly`），安装完成后即可开始使用
- **使用**：组装过程中随时提问，agent 会按技能内置的 14 步教程、零件对照表和排错手册给出针对性回答，例如：
  - "下一步做什么？"
  - "这颗 M5×30 螺丝装在哪里？"
  - "装完电机不动怎么办？"

一套零基础也能做出来的**相机电动滑轨**：亚克力激光切割 + 3D 打印 + 欧标铝型材，配步进电机驱动，可实现平滑的推拉运镜。全部图纸、3D 打印文件、材料清单、组装教程开源在本仓库。


##  找商家定制怎么说

需要找商家加工的只有下面几项，其余零件照 `材料清单/导轨材料清单.xlsx` 直接网购即可：

**① 亚克力板（激光切割）** —— 把 `亚克力图纸/` 里 3 个 DXF 文件发给激光切割商家
> 我要激光切割亚克力，图纸是 DXF 共 3 个：01 号 8mm 厚切 2 块、02 号 5mm 厚切 1 块、03 号 3mm 厚切 1 块，一共 4 块，请按文件 1:1 切割。

> 💡 如果你**有 3D 打印机**：可以自己打印等效的板件（仓库 `3D打印文件/` 里的 3MF 含全套板件），就**不需要**找商家定制亚克力了。

**② 3D 打印代工（仅限没有打印机时）** —— 把 `3D打印文件/` 里 2 个 3MF 文件发给代打印商家
> 这是两个 3MF 文件：一个含滑轨全套打印件，一个是 M3 塑料螺丝×10，请按文件设置直接打印，不需改尺寸。

**③ 铝型材攻丝** —— 买欧标 2040V 铝型材时给商家留言
> 请帮我把这根型材的两个端面攻好螺纹孔，后面装支架用。**M5 或 M6 都可以，跟商家说清用哪种即可。**

## ⚠️ 关键注意事项

- **控制板固定必须用 3D 打印塑料螺丝**（或笔记本小螺丝/M2 螺丝+绝缘垫片）。金属螺丝会顶到电路板背面造成短路烧板！
- 烧带锡热缩管时远离易燃物，烧到锡熔化即停，接头烫手等冷却再碰
