# 04 · 常见错误排查 + 安全注意事项

## 一、排错表（按"用户说现象 → 回答可能原因 → 给处理办法"使用）

### 电机 / 控制板类

| 现象 | 可能原因（按概率排序） | 处理办法 |
|---|---|---|
| 上电后控制板冒烟/烧了 | ①用金属螺丝固定控制板，顶到背面线路短路 | 立即断电。换 3D 打印塑料螺丝或笔记本小螺丝+绝缘垫片重新固定；板子大概率已损坏需更换 |
| 电机一点不动 | ①电池没电/没接好 ②驱动板接线松 ③遥控器没配对 | 先查电池 DC 头插紧没；再逐个按压驱动板上的接线端子；最后看套装说明书重新对码配对 |
| 电机嗡嗡响但不动 | ①同步带绷太紧 ②同步带没咬进同步轮齿里 | 松一点两端顶丝重新绷带；确认皮带齿对准轮齿卡进去 |
| 滑车走到头不停/撞端盖 | ①限位开关接线接反排 ②线头假焊（热缩管烧了但没焊牢） | 对照"蓝紫→最下一排、橙黄→上一排"重新插线；轻拽线头检查是否焊牢，假焊的重新烧一次 |
| 电机只在半程回头/提前停 | 限位开关翘板被刮到或位置装反 | 检查开关翘板朝向，调整到只有滑车能碰到 |

### 机械类

| 现象 | 可能原因 | 处理办法 |
|---|---|---|
| 轮子装完晃/车跑起来歪 | ①4 颗 M5×30 下面垫高不一致（圆锥数量不同或螺母数量不同）②自锁螺母没拧紧 | 统一每颗螺丝的垫高（要么全用圆锥、要么全串 3 颗 M5 螺母）；重新用钳子拧紧 |
| 轮子转不动 | 自锁螺母拧太死 | 松半圈，以"不晃、能拨动"为准 |
| 云台松动/拧不紧 | 1/4 螺丝没从底座孔下方穿、或没从下面用六角刀顶住拧紧 | 拆下重新装：螺丝从底座中间孔**下方**往上穿，云台拧上后从下面顶紧 |
| 螺丝拧不进铝型材孔 | 型材端面没攻丝 | 找商家补攻丝，或自己用 M5/M6 丝锥攻丝（参考下文安全区"攻丝"条） |
| 同步带打滑/跳齿（走的时候咔咔响） | 带子太松 | 松开一端顶丝，重新绷紧再固定 |
| 电机转着吃力/发烫 | 同步带绷太紧 | 适当放松，按下去有轻微弹性即可 |
| 同步带接头松脱 | T 型螺母没塞进槽里或顶丝没顶紧 | 确认 T 型螺母卡进型材凹槽、M5 顶丝压实带子 |
| 滑车推起来卡顿 | 轮子没卡进型材凹槽正中 | 把滑车抬起来重新对准凹槽放入 |
| 亚克力板孔位对不上 | 板的厚度/位置用错（4 块板厚度不同：8mm×2、5mm、3mm） | 按厚度重新分堆；对照图纸文件名核对每块用在哪 |

### 3D 打印 / 配件类

| 现象 | 可能原因 | 处理办法 |
|---|---|---|
| 没有 3D 打印螺丝固定控制板 | 没打印或没买打印件 | 用笔记本电脑小螺丝，或 M2 螺丝+绝缘垫片代替（必须是非导电方案） |
| 没有垫高圆锥 | 没打印 | 每颗 M5×30 螺丝串 3 颗 M5 普通螺母垫高（官方口播稿认可的替代方案） |
| 打印件孔太紧装不上 | 打印公差 | 用小刀轻修孔边毛刺，别硬砸 |

## 二、安全注意事项（凡涉及对应操作必须先说）

1. **打火机烧焊（第 9 步）**：只烧带锡热缩管、几秒即停；远离易燃物；烧完的接头烫，凉了再碰；烧过头会熔化线皮造成断线。
2. **攻丝（第 10 步）**：丝锥要对准孔、垂直旋入，边旋边倒半圈排屑；硬拧会断丝锥（断在里面很难取出，基本报废）。
3. **锂电池（第 12 步）**：不要短路两极、不要刺破外壳；充电用原装/配套充电器，人不要离岗；魔术贴固定既防摔也方便取下充电。
4. **上电测试**：第一次通电前再过一遍接线颜色（蓝紫→最下排、橙黄→上一排）；手指远离同步轮和同步带，电机运转时不要伸手入轨。
5. **裁剪同步带**：绷紧状态下裁剪时刀口朝外，避免割手；裁完马上给切口修齐。
6. **钳子使用**：夹自锁螺母时手指不要放在钳口与螺母之间。

## 三、回答时的补充规则

- 用户描述的现象不在表里时：让用户拍下/描述"哪一步、装到什么程度、出现什么声音或现象"，再按最接近的条目推断，并明确说"这是最可能的原因"。
- 涉及烧板、断丝锥这类不可逆损失，回答里要给出"如何避免再次发生"的一句提醒。
- 用户问"我这样装对不对"时，让用户对照 03 号文件末尾的"完工自检清单"逐条核对。
